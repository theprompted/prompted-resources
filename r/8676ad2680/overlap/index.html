01Get started in four steps

You need Claude Code already installed (you're a paid Claude subscriber) and a fal.ai API key (that's what generates the images). That's the only assumption — Claude Code installs the rest.

  1. Download the zip using the button above. Move it to your Desktop and double-click to unzip. You'll get a folder called overlap.
  2. Open Claude Code in that folder. In Terminal (Mac) or Command Prompt (Windows): cd ~/Desktop/overlap && claude Windows: cd %USERPROFILE%\Desktop\overlap && claude
  3. Add your fal.ai key. Once you see the ❯ prompt, tell Claude Code: set up the overlap skill — here's my fal.ai key: ... It will install the skill and the fal-client library, and save your key to a local .env. Grab a key at fal.ai if you don't have one.
  4. Run it on a design. Point it at any finished design and tell it who buys: /overlap — design: ~/Desktop/my-design.png — buyer: an ER nurse who lives on coffee It writes the prompts, shows them, and on your ok generates the images — grouped by reason, named for you, into an images/ folder with a review grid.
⚠ Heads up — image credits

Image generation runs on your fal.ai key, so each batch costs a few cents per image. Start with a small count per reason (3–5) to dial in your design, then scale the count up once the scenes look right.

02What's in the bundle

One skill that does the whole chain — write the scene prompts, generate the images, build a review grid:

overlap

Flat design → finished ad scenes, held pixel-faithful

Takes one design + a buyer and writes N reference-image prompts per buying reason (be seen / feel something / gift it), each engineered to keep the design ≥55–60% of the chest, legible, and facing the camera. Then it batch-generates the images via NanoBanana 2 (/edit mode, the design locked as the reference) and builds a keep/regenerate review grid. Trigger phrases: "turn this design into ads", "run the overlap", "make ad scenes from this design".

The three reasons are the default; if your buyer's wants differ, give the skill yours and it builds the batch around those instead.

03If something goes wrong

Just describe what you saw to Claude Code. It can read its own skill and the generation script, parse error messages, and walk you through fixes interactively.

The most common issues:

  • The text on the shirt comes out garbled — long on-shirt phrases (8+ words) garble in some models. Shorten the design's text or re-run; a clean reference image in = a clean design held across every scene out.
  • The design is hidden by arms / turned away — tell the skill to bake a clearer posture into the prompt (arms relaxed at the sides, prop held to the hip). Arms across the chest ruins the ad.
  • fal.ai returns 401 — your FAL_KEY is missing or wrong. Tell Claude Code and it'll help you re-check your .env.
