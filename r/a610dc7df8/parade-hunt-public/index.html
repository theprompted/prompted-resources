Parade Hunt

Find the print-on-demand crowds worth chasing. It seeds and scores around thirty candidate crowds against each other, ranks them by size and how easily they buy, then deep-audits the winner into the language, design angles, and shirts to print.

  • A market scan: ~30 candidate crowds seeded from what you tell it, each scored on size and ease-of-conversion, ranked so no two members chase the same one
  • A deep audit of any one: the crowd’s in-group language, the design angles that fit, ~10–12 ready-to-print phrases, and the first 5 shirts to test
  • Delivered as a clean HTML report you can build designs straight from

01Get started in three steps

You need Claude Code already installed (you're a paid Claude subscriber). That's the only assumption.

  1. Download the zip using the button above. Move it to your Desktop and double-click to unzip. You'll get a folder called parade-hunt.
  2. Copy it into your skills folder. Move the parade-hunt folder into .claude/skills/ in your project (or your home folder's .claude/skills/ to make it available everywhere). If you're not sure, open Claude Code and ask it: "install the parade-hunt skill from this folder." cp -r ~/Desktop/parade-hunt ~/.claude/skills/
  3. Run it. Open Claude Code and start the skill. It asks what you’re into, seeds ~30 crowds from your answer, scores and ranks them, then deep-audits the parade you pick. /parade-hunt find me parades
⚠ Heads up — give it room to research

The scan does real web research across each candidate crowd (their communities, videos, marketplaces) before it scores them. That’s what makes the output specific instead of generic. A full scan plus audit takes a few minutes. Let it run.

02What's in the skill

One skill, run as a guided flow:

Step 1 — Seed + Scan

Seeded, scored crowds

Asks what you’re into, then seeds ~30 candidate crowds branched off your answer (so two people never get the same list), researches each, and scores them on size and ease-of-conversion. Ranked by opportunity, so you know which parade is worth building for. Then it asks which one to go deep on.

Step 2 — Audit (the crowd)

Their language + the angles

For the parade you pick: an honest read on whether it’s a real refilling crowd, then the in-group language they actually use — the jokes, shared pains, and shorthand that belong on a shirt — and the design angle families that fit them.

Step 3 — Audit (the designs)

Phrases, shirts, and the look

A starter phrase library (~10–12, shirt-ready, in the crowd’s own words), the first 5 shirts to test, and the visual codes (palette, type, iconography) that signal “this is for us.” Everything written up as a clean HTML report.

03If something goes wrong

Just describe what you saw to Claude Code. It can read its own skill file, see where it stopped, and pick up from there.

  • Output feels generic — it usually means the research step got skipped or thin. Tell it to "redo the scan with real web research first" and name where the crowd hangs out (their communities, the marketplaces they buy on, their videos).
  • It gave you crowds but no audit — tell it "now deep-audit the one I picked." The full audit (language, angles, phrases, shirts) is the whole point.
  • The skill isn't found — confirm the parade-hunt folder is inside .claude/skills/ and restart Claude Code.
