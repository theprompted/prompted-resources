01Get started in three steps

You need Claude Code already installed (you're a paid Claude subscriber). That's the only assumption. The skill is pure prompt logic plus one small Python helper for the optional image generation.

  1. Download the zip using the button above. Move it to your Desktop and double-click to unzip. You'll get a folder called tattoos-not-fashion.
  2. Drop the skill into your Claude Code skills folder (or open Claude Code in a project and copy it into .claude/skills/). In Terminal: cp -r ~/Desktop/tattoos-not-fashion ~/.claude/skills/tattoos-not-fashion The generation step (optional) uses fal.ai — set a FAL_KEY env var, or pass --env-file to generate.py, only if you choose to generate. Nothing spends until you say so.
  3. Run it. Once you see the ❯ prompt, invoke the skill and give it one crowd you understand: /tattoos-not-fashion It reflects the crowd back, weights the three tattoo reasons, builds the concepts and prompts, then stops at a spend gate and asks before it generates a single image.
ⓘ The chain it belongs to

Tattoos, Not Fashion is the last link: /parade-hunt (find the crowd) → /identity-decoder (know the crowd) → /tattoos-not-fashion (make the shirt). It's strongest on a real decode — the reason-weighting and concepts are only as good as the understanding of the crowd underneath them. It works on a lighter read too; it'll just tell you it's lighter. It's a sibling to Make The Flag: same input, a different lens (three tattoo reasons instead of twelve flags).

02What's in the bundle

The full skill plus its runnable generation capability:

tattoos-not-fashion (SKILL.md)

The full tattoo-lens engine — reason-weighting, concepts, art-directed prompts

Reads how much of the crowd's emotional charge lives in each of the three reasons, derives a twenty-slot split from it (never guessed), spins concepts spread across each reason's sub-angles (mixing phrases, coined words, and design/motif ideas), then turns each into a dense, fully art-directed generation prompt — flat white artwork on black, full composition, named style. It reflects first, presents as a choice, and never auto-generates.

generate.py

The generation capability — three modes, dry-run by default

Turns your prompts into sample images once you approve the spend. Three modes: ideogram (typography-forward flat artwork, the default for these designs), t2i (garment mockup scenes), and edit (hold an existing flat design exact via a reference image). It will not spend a cent unless you pass --go — the default is a dry run that just shows you what it would generate.

The skill deliberately stops before spending money, so you decide which concepts are worth generating.

03If something goes wrong

Just describe what you saw to Claude Code — it can read the skill's own files and walk you through fixes.

The most common things:

  • Concepts feel thin — almost always the crowd was too broad. Give it a tighter slice ("women who run slow and know it, back-of-the-pack" beats "runners"). The richer the crowd, the sharper the reasons.
  • The split looks random — it should always be able to point at something about the crowd for why a reason leads. If it can't, the read of the crowd was too thin; feed it more texture and re-run.
  • Generation errors on --go — the FAL_KEY isn't set. Set the env var or pass --env-file path/to/.env. Without a key it stays in dry-run and spends nothing.
  • Text garbles in a generated image — the on-shirt text is too long. Keep it to 2–7 words; regenerate (it's cheap), or shorten the phrase.
