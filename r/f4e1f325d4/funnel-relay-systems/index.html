03Get started in four steps

You need Claude Code already installed (you're a paid Claude subscriber). That's the only assumption. Claude Code installs everything else for you — Python, the fal-client library, and your API key configuration — automatically.

  1. Download the zip using the button above. Move it to your Desktop and double-click to unzip. You'll get a folder called funnel-relay-system.
  2. Open Claude Code in that folder. In Terminal (Mac) or Command Prompt (Windows): cd ~/Desktop/funnel-relay-system && claude
  3. Tell Claude Code to set up the system. Once you see the ❯ prompt, paste: set up the funnel relay system Claude Code will detect what's missing, install Python and fal-client, prompt you for your FAL_KEY, and copy all 7 skills into place. It tells you what it's doing at each step.
  4. Run your first funnel. Once setup completes, paste: run the funnel relay on [PRODUCT URL] Claude Code handles the whole pipeline. A full run takes ~2.5–3.5 hours and costs roughly $0.20–$0.50 in fal credits.
→ You'll need a fal.ai key

The relay uses fal.ai for image generation. Free signup, pay-as-you-go (roughly $0.04–$0.10 per image, 5 images per funnel). Setup will prompt you for the key — grab one at fal.ai/dashboard/keys before you start.

⚠ Heads up — password prompts

If your machine doesn't have Python yet, Claude Code may ask for your computer password to install Homebrew (Mac). That's normal — type your password into the Terminal window when you see the prompt. You won't see characters as you type. Press Enter when done.

04If something goes wrong

Just describe what you saw to Claude Code. It can read its own scripts, parse error messages, and walk you through fixes interactively — that's the whole point.

The most common stumble is FAL_KEY not set — usually because you opened a new terminal without sourcing the .env from setup. Run set -a; source .env; set +a and retry. If you see a 401 from fal, your key is bad — regenerate at fal.ai/dashboard/keys. A 402 means you're out of fal credits.

If a leg seems to hang for more than a few minutes, there's usually a stale tail -f still attached to a finished log. Kill it (ps aux | grep tail → kill <pid>) and the next leg picks up.

If L9 keeps failing after 2 retries, the relay halts and waits for human review. Open qa-report.md in the relay directory — usually L6 (page-one) is using transformation language ("transform", "amazing", "revolutionary") or has drifted off the locked strategy. Fix the draft manually or restart with a different segment.
